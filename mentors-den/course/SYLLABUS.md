# 家庭编程课 · 12 周完整大纲

> 一套材料，两位学员。每课 30-45 分钟。🏆 = 项目周
>
> **作业提交规范（v1.2 学员 8/30 立）：** 上手练习存为 `{W-L}-practice.py`（如 W01-L01-practice.py），课后作业存为 `{W-L}-homework.py`（如 W01-L02-homework.py）——全部交到 `thawpaw/homework/` 目录（已 .gitignore）。mentor 评语出现在 `thawpaw/reviews/*.review.md`。旧命名（如 W01-robot.py / W01-my_vars.py）转正保留，新课按新约定。详见 `mentors-den/mentors-rules.md` v1.2 ⑧⑨。

## 第一阶段：语言基础（W01-W05）

### W01 · 起步：让程序开口说话
| 课 | 主题 | 你将能做到 |
|---|---|---|
| L01 | 认识终端 + 装 Thonny + 第一行 print | 写出并运行第一个程序 |
| L02 | 变量：给东西起名字 | 用盒子装数据、改数据 |
| L03 | input 让程序提问 + 第一个计算器 | 程序跟你对话并算数 |
| 🏠 周末项目 | 自我介绍机器人 | 问 4 个问题，总结成一段话 |

### W02 · 数字与文字魔法
| 课 | 主题 | 你将能做到 |
|---|---|---|
| L01 | 数字与类型（"2026" ≠ 2026） | 分清文字和数字，会转换 |
| L02 | 字符串功夫（大小写/长度/替换） | 像变魔术一样处理文字 |
| L03 | f-string：漂亮地说话 | 一行搞定复杂输出 |
| 🏠 周末项目 | 名字实验室 + 单价订单计算器 | 综合运用 |

### W03 · 让程序做决定
| 课 | 主题 | 你将能做到 |
|---|---|---|
| L01 | 如果……那么（if + 比较） | 程序会看情况办事 |
| L02 | 否则怎么办（else / elif） | 多分支判断 |
| L03 | and / or / not 组合条件 | 复杂逻辑（成绩等级评定器） |
| 🏠 周末项目 | 猜大小游戏 v1 | 一次猜数，程序告诉你高低 |

### W04 · 让程序重复干活
| 课 | 主题 | 你将能做到 |
|---|---|---|
| L01 | for 循环 + range | 让程序重复 100 次也不累 |
| L02 | 累加器模式 | 求和、计数、找最大 |
| L03 | 嵌套循环 | 画楼梯、金字塔 |
| 🏠 周末项目 | 图案集：楼梯 + 金字塔 + 九九乘法表 | — |

### W05 · 直到……才停
| 课 | 主题 | 你将能做到 |
|---|---|---|
| L01 | while：条件不满足就一直转 | 死循环与活循环 |
| L02 | break：喊停的艺术 | 退出条件设计 |
| L03 | 猜数字完整版（循环+判断合体） | 本阶段集大成 |
| 🏠 周末项目 | 打磨猜数字：限 5 次 + 计分 + 再来一局 | — |
